# Site previews

Preview pages are the approval surface for visual changes. They are deliberately excluded from navigation and search indexing.

Workflow:

1. Build and publish the proposed treatment in `previews/`.
2. Review the stable preview URL at desktop and mobile sizes.
3. Revise the preview until approved.
4. Promote only the approved rules and markup to the production page.
